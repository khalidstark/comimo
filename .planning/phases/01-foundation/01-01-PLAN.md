**Design direction (proposal for the user to approve at the checkpoint):**
- Feel: a hand-printed comic zine about your own life. Paper with a faint halftone dot texture, ink outlines, panel gutters as the layout grid, sticker-like characters.
- Palette tokens: newsprint paper (cool off-white, not cream), deep ink navy, riso pink as the accent, sunflower yellow for highlights, teal for calm and check-in moments. Mood colours for day weather are separate semantic tokens (sunny, cloudy, rainy, stormy, rainbow).
- Type: one display face and one body face that both cover Arabic and Latin (candidates: Baloo Bhaijaan 2 for display, IBM Plex Sans Arabic for body), plus a hand-lettering face for speech bubbles. Load with next/font/google.
- Motion: cinematic, story-like transitions (panel wipes, page turns, camera pans), light airy sections after the hero. Avoid iris and plain dissolve transitions (user dislikes them). Respect prefers-reduced-motion.
- Both light and dark themes from the same tokens.
- `dir="auto"` on user text; the app chrome is English with Arabic-ready layout using logical CSS properties (margin-inline, padding-inline).

**Constraints:**
- Write all code fresh. `/Users/khalid/projects/comicLife-main.zip` may be read for logic ideas only; never copy code from it.
- No images copied from the internet. Until the Meta credits arrive, art is placeholder SVG drawn in code and clearly labelled as a placeholder.
</context>
